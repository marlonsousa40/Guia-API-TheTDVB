Chave da API do TheTVDB

Siga este guia rápido para criar API TheTVDB. Você precisará de uma chave de API para permitir que os aplicativos extraiam metadados do TheTVDB.

Guia de cadastro do e-mail
Você pode utilizar um e-mail temporário gerado ou o seu próprio e-mail pessoal para este cadastro.
1

Gerar um e-mail temporário (Opcional)

Clique aqui ↗ para gerar um endereço de e-mail temporário. Ele será necessário apenas para o cadastro. Mantenha esta página aberta.

Ou você pode utilizar o seu próprio e-mail pessoal.

2

Criar uma conta

Crie sua conta

  1. Clique aqui ↗ para abrir a página de cadastro da conta TheTVDB.
  2. Insira um nome de usuário e uma senha, seguidos pelo e-mail temporário gerado na etapa anterior (ou seu próprio e-mail). Em seguida, clique em "Register".
  3. Vá ao site do e-mail gerado ou na caixa de entrada do seu e-mail próprio, abra a mensagem do TheTVDB e clique no link de verificação para confirmar sua conta.
3

Criar sua chave de API

  1. Clique aqui ↗ para abrir a página da API do TheTVDB.
  2. Clique no botão "Get Started".
  3. Preencha os dados do formulário:
    Company or Project Name: Stremio Streaming
    Project Description: Quero transmitir conteúdo com metadados do TheTVDB
  4. Clique no botão "Submit".
Parabéns! 🎉
Sua conta TheTVDB foi criada e a chave de API gerada!
Para acessar sua chave de API a qualquer momento no futuro, visite thetvdb.com/dashboard/account/apikey.

Agora é só copiar a chave e ser feliz.
